# ML Model Implementation from Scratch

This repository contains simple and educational implementations of popular Machine Learning (ML) algorithms coded from scratch using **Python** and **NumPy**. It is designed to help learners understand the inner workings of core ML concepts like gradient descent, loss functions, and model evaluation — without relying on high-level libraries like scikit-learn.

---

## 📂 Project Structure

```
ML_model_implementation_from-scratch/
│
├── linear_reg.py               # Linear Regression class (from scratch)
├── linear_reg_main.ipynb       # Notebook to run Linear Regression
│
├── logistic_reg.py             # Logistic Regression class (from scratch)
├── logistic_reg_mian.ipynb     # Notebook to run Logistic Regression (typo in 'main')
│
├── percep.ipynb                # Perceptron algorithm implementation
│
└── __pycache__/                # Compiled Python files (auto-generated)
```

---

## ✅ Implemented Models

- **Linear Regression**  
  - Gradient Descent Optimization  
  - Mean Squared Error (MSE) Loss  
  - Visualization and Evaluation

- **Logistic Regression**  
  - Sigmoid Activation  
  - Binary Cross-Entropy Loss  
  - Accuracy Calculation

- **Perceptron**  
  - Basic Binary Classifier  
  - Step Function Activation  
  - Suitable for Linearly Separable Data

## 🚀 Getting Started

Clone the repo and run the notebooks:

```bash
git clone https://github.com/Devilvamp17/ML_model_implementation_from-scratch.git
cd ML_model_implementation_from-scratch
```

Open the notebooks with Jupyter:

```bash
jupyter notebook
```
